# 🤖 Telegram Bot для Сервисного центра

Этот Telegram-бот предназначен для автоматизации приема и обработки заявок в сервисном центре по ремонту компьютеров и оргтехники. Он позволяет клиентам оставлять заявки, а администратору — эффективно управлять ими через удобный интерфейс.

## ✨ Основные возможности

Бот разделен на две основные части: для клиентов и для администратора.

### 👤 Для клиентов
*   **Главное меню** с навигацией по функциям.
*   **Создание заявки на ремонт**: пошаговый сбор информации: выбор типа проблемы из списка, ввод имени, номера телефона и подробного описания.
*   **Просмотр своих заявок**: клиент может видеть историю своих обращений и их текущий статус (Новая, В работе, Готово).
*   **Просмотр контактной информации и цен** (заглушки, которые можно заполнить реальными данными).

### 👨‍💼 Для администратора
*   **Защищенная админ-панель** по команде `/admin` (доступна только пользователю с указанным `ADMIN_ID`).
*   **Просмотр всех заявок** с пагинацией (по 5 штук на странице).
*   **Фильтрация заявок по статусу**: "Новая", "В работе", "Готово".
*   **Управление статусом заявки**: администратор может изменить статус прямо из карточки заявки.
*   **Уведомление клиента**: при изменении статуса заявки клиент автоматически получает уведомление в Telegram.
*   **Просмотр статистики**: общее количество заявок, количество за сегодня и разбивка по статусам.
*   **Просмотр контактов клиента**: имя, телефон и Telegram ID.

## 🛠 Технологии

*   **Python** 3.7+
*   **python-telegram-bot** (библиотека для работы с Telegram Bot API)
*   **SQLite** (легковесная база данных для хранения заявок)
*   **python-dotenv** (для загрузки переменных окружения из файла `.env`)
